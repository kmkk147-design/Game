# Game — 선 따라 쓱쓱! 🎨

5살 어린이부터 즐기는 모양 따라 그리기 웹 게임입니다. 아이폰/안드로이드 터치와 PC 마우스를 지원합니다.

## 규칙

- 모양 20개(쉬움 8개, 보통 6개, 도전 6개)
- **제한시간 10초**. 마지막 **5초**에는 빨간 타이머와 틱탁 효과음
- **한 판 한 번의 연속된 선만** 그릴 수 있습니다. 손가락/마우스를 떼는 순간 즉시 채점하며, 같은 판에서 추가 획이나 지우기는 불가합니다.
- 목표 선의 실제로 따라 그린 비율과 그린 선의 **윤곽선과의 거리**를 함께 채점합니다. 목표 선에서 벗어나거나 대충 따라 그리면 감점됩니다. 지나치게 긴 반복 낙서 역시 감점됩니다.
- **70% 초과 합격** 시 축하 폭죽, **70% 이하 실패**. 10초 초과 시 폭탄 폭발 후 시간 초과
- 결과 화면에서 **다시 도전**하면 새로운 10초 도전이 시작됩니다.
- 소리 켜고 끄기 가능, 개인 정보 수집/저장 없음, 외부 라이브러리 없음

## 배포

정적 HTML 단일 파일 `index.html`입니다. Vercel 프로젝트 `game`에 정적 사이트로 배포합니다.
