# Game — 선 따라 쓱쓱! 🎨

5살 어린이용 모양 따라 그리기 웹 게임입니다. 8가지 그림을 터치 또는 마우스로 따라 그립니다.

- 시작 버튼을 누르면 **30초** 카운트다운 시작
- **10초 이하**가 되면 붉은 타이머, 틱탁 안내 및 효과음 (소리 끄기 가능)
- **70% 초과** 완성 시 합격, 불꽃놀이 및 축하 효과음
- **70% 이하** 시 격려와 실패 표시
- **30초 초과** 시 폭탄 '펑' 연출과 시간초과 실패 표시
- 선의 길이를 따라 샘플링하여 커버리지(85%) 및 선에서 벗어나지 않은 정도(15%)로 평가. 어린이용 손떨림 오차 허용.
- HTML 한 파일로 동작. 개인정보 수집/저장 없음. 외부 라이브러리 없음.

## 실행

`index.html`을 브라우저에서 열면 됩니다. Vercel에서는 정적 사이트로 배포하면 됩니다.
