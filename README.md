# GAME — 키즈 플레이 아케이드 🎨🐹🚒

아이폰/안드로이드/PC에서 터치·마우스로 즐기는 **3가지 어린이 웹 게임**. 별도 앱 설치, 서버 계정, 외부 JS 라이브러리 없이 작동합니다.

## 1. 🖍️ 색칠공부 (선 따라 쓱쓱!)
- 쉬움·보통·도전 단계의 그림 24개(각 8개)
- 10초 안에 손 떼지 않고 한 번에 윤곽선 따라 그리기
- 손을 떼면 점수 확정, 한 판 한 번의 기회
- 100점 만점 감점제: 그리지 않은 부분, 윤곽선 이탈 거리(가벼움/중간/큼), 반복 낙서를 각각 감점
- 75점 **초과** 합격 → 축하 폭죽. 75점 이하 및 시간 초과 → 실패

## 2. 🐹 두더지 게임
- 30초 제한, 3×3 두더지 구멍, 두더지 뿅망치로 치기
- 성공 시 뿅 소리·망치 스윙·반짝 이모티콘과 함께 두더지 내려감
- 연속 적중 점수 보너스, 결과·재도전

## 3. 🚒 소방서 게임
- 25개 창문의 아파트에서 랜덤으로 불 발생
- 각 불은 나타난 후 정확히 3초가 지나면 그 창문이 타버림
- 60초 동안 불 끄기, 콤보 점수·피해창문 표시
- 결과 화면에서 소방관 이름으로 기록 저장 및 순위표 표시
- **순위는 현재 사용 중인 브라우저/기기에만 저장됩니다(localStorage).** 전 사용자 공통 서버 순위가 아니며 다른 기기와 자동 공유되지 않습니다.

## 배포

`index.html`, `arcade.css`, `arcade.js`를 Vercel의 정적 웹 프로젝트 `game` 루트에 배포합니다.

개인정보/로그인 서버 없음. 기록은 사용자의 브라우저에서만 저장됩니다. Safari 개인정보 보호 설정·시크릿 모드에서 저장이 차단될 수 있습니다.
## 2026-10-31 조정

- 따라 그리기 점수는 실제 윤곽선 커버리지, 30 SVG단위까지의 근접 정확도, 과한 낙서 길이를 함께 평가합니다. 가까운 터치는 점수를 조금 인정하지만 선을 크게 벗어난 그리기는 점수를 잃습니다.
- 소방서는 60초 동안 5단계로 어려워집니다: 0–12초 1곳, 12–25초 최대 2곳, 25–38초 최대 3곳, 38–50초 최대 4곳, 50–60초 최대 5곳 동시 화재. 단계별로 여러 창문에 동시에 불이 붙을 수 있으며 각각 3초 안에 꺼야 합니다.

## 그림 그리기 채점 개편

색칠공부의 결과를 백분율이 아닌 **100점 만점 점수**로 표시합니다. 75점 초과 합격 조건은 유지합니다. 실제로 따라 그리지 않은 목표 선의 구간을 감점하고, 그린 선이 목표 윤곽선에서 멀어질수록 **살짝 이탈 → 중간 이탈 → 크게 이탈**의 단계별 감점을 누적합니다. 같은 곳을 반복하거나 과하게 길게 낙서한 부분도 별도 감점합니다. 게임 도중에는 현재 감점, 판정 후에는 감점 항목별 점수가 표시됩니다. 색칠공부만 변경하며 두더지·소방서 규칙과 기록은 그대로 유지합니다.

## 그림 수준 소폭 상향 (2026-10-31)

기존 20개 중 **집(굴뚝), 아이스크림(둥근 크림), 물고기(등지느러미), 고양이(얼굴 윤곽)**의 선형을 조금 더 자세하게 수정했습니다. **우산·선물상자(보통), 토끼·돛단배(도전)** 4개를 추가하여 쉬움 8개/보통 8개/도전 8개로 구성했습니다. 모두 한 번에 이어 그릴 수 있는 단일 윤곽선입니다. 기존 10초 제한, 한 번 그리기, 감점제, 다른 게임 기능은 유지합니다.
