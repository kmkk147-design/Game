# GAME — 키즈 플레이 아케이드 🎨🐹🚒⚽🌈

아이폰/안드로이드/PC에서 터치·마우스로 즐기는 **6가지 어린이 웹 게임**. 별도 앱 설치, 서버 계정, 외부 JS 라이브러리 없이 작동합니다.

## 1. 🖍️ 색칠공부 (선 따라 쓱쓱!)
- 쉬움·보통·도전 단계의 그림 24개(각 8개)
- 20초 안에 손 떼지 않고 한 번에 윤곽선 따라 그리기
- 손을 떼면 점수 확정, 한 판 한 번의 기회
- 100점 만점 감점제: 그리지 않은 부분, 윤곽선 이탈 거리(가벼움/중간/큼), 반복 낙서를 각각 감점
- 80점 **이상** 합격 → 축하 폭죽. 79점 이하 및 시간 초과 → 실패

## 2. 🐹 두더지 게임
- **60초 제한**, 3×3 구멍에서 나타나는 두더지와 고양이를 뿅망치로 치기. 시작 **0~5초는 1마리**, 그다음은 **5~14초 2마리 → 14~23초 3마리 → 23~33초 4마리 → 33~43초 5마리 → 43~52초 6마리 → 52~60초 7마리** 동시 등장. 후반에는 등장 지속 시간이 짧아지고 고양이 출현 확률도 높아집니다.
- 두더지 적중 시 뿅 소리·망치 스윙·반짝 이모티콘과 함께 두더지 내려감. 고양이(약 30% 확률)를 치면 20점 감점, 고양이는 메롱하며 혀를 내밀고 놀린 뒤 내려감. 고양이를 피하면 감점 없음
- 연속 적중 점수 보너스, 결과·재도전. **게임 종료 후 이름(최대 12자)과 점수를 저장**할 수 있으며, 두더지 게임 전용 순위표에서 최고 20개 기록을 볼 수 있습니다. 점수 내림차순, 동점 시 두더지를 많이 잡은 순, 그다음 고양이를 적게 친 순으로 정렬합니다. 기록은 현재 사용 중인 **브라우저/기기에만 저장**됩니다(localStorage).

## 3. 🚒 소방서 게임
- 25개 창문의 아파트에서 랜덤으로 불 발생
- 각 불은 나타난 후 정확히 3초가 지나면 그 창문이 타버림
- 60초 동안 불 끄기, 콤보 점수·피해창문 표시
- 결과 화면에서 소방관 이름으로 기록 저장 및 순위표 표시
- **순위는 현재 사용 중인 브라우저/기기에만 저장됩니다(localStorage).** 전 사용자 공통 서버 순위가 아니며 다른 기기와 자동 공유되지 않습니다.

## 배포

`index.html`, `arcade.css`, `arcade.js`, `balloon-match.html`, `pet-care.html`, `pet-care.css`, `pet-care.js`와 기존 정적 이미지/아이콘을 Vercel의 정적 웹 프로젝트 `game` 루트에 함께 배포합니다.

개인정보/로그인 서버 없음. 기록은 사용자의 브라우저에서만 저장됩니다. Safari 개인정보 보호 설정·시크릿 모드에서 저장이 차단될 수 있습니다.
## 2026-10-31 조정

## 그림 그리기 채점 개편

색칠공부의 결과를 백분율이 아닌 **100점 만점 점수**로 표시합니다. 합격 기준은 80점 이상(80점 포함)입니다. 실제로 따라 그리지 않은 목표 선의 구간을 감점하고, 그린 선이 목표 윤곽선에서 멀어질수록 **살짝 이탈 → 중간 이탈 → 크게 이탈**의 단계별 감점을 누적합니다. 같은 곳을 반복하거나 과하게 길게 낙서한 부분도 별도 감점합니다. 게임 도중에는 현재 감점, 판정 후에는 감점 항목별 점수가 표시됩니다. 색칠공부만 변경하며 두더지·소방서 규칙과 기록은 그대로 유지합니다.

## 그림 수준 소폭 상향 (2026-10-31)

기존 20개 중 **집(굴뚝), 아이스크림(둥근 크림), 물고기(등지느러미), 고양이(얼굴 윤곽)**의 선형을 조금 더 자세하게 수정했습니다. **우산·선물상자(보통), 토끼·돛단배(도전)** 4개를 추가하여 쉬움 8개/보통 8개/도전 8개로 구성했습니다. 모두 한 번에 이어 그릴 수 있는 단일 윤곽선입니다. 기존 20초 제한, 한 번 그리기, 감점제, 다른 게임 기능은 유지합니다.

## 합격 기준 조정

그림 따라 그리기는 **80점 이상 합격**으로 변경했습니다. 80점은 합격, 79점은 불합격입니다. 기존 단계별 감점 기준과 난이도 24개, 20초 한 번 그리기는 그대로 두어 연습하면 도전할 수 있도록 했습니다. 다른 두 게임의 규칙은 변경하지 않았습니다.

## 두더지 화면 개선 (2026-10-31)

기존 이모지 대신 CSS로 귀·눈·코·앞발이 있는 귀여운 두더지와 귀가 뾰족하고 수염·줄무늬·혀가 있는 고양이를 그립니다. 고양이는 최대 연속 2회 등장하고, 고양이를 잡으면 점수는 최소 0점까지 20점 감소하며 연속 잡기 기록이 초기화됩니다. 맞은 고양이는 잠깐 메롱한 후 내려갑니다. 화면 하단을 과도하게 차지했던 진녹색 잔디 배경과 녹색 앞턱을 제거하고 밝은 오락실 무대로 정리했습니다. 그림 따라그리기와 소방서는 변경하지 않았습니다.


## 2026-10-31 두더지·소방서 확장

### 두더지 게임
- 30초 / 9개 구멍. 0~7초에는 한 마리씩, 7~17초에는 2마리씩, 17초 이후에는 3마리가 동시에 등장합니다. 각 구멍은 독립적으로 터치 판정되며 여러 마리를 빠르게 연속해서 잡을 수 있습니다.
- 고양이 출현 확률은 초반 약 22%, 중반 약 32%, 후반 약 39%로 변화합니다. 2~3마리 동시 등장할 때 최소 1마리는 두더지입니다.
- 두더지 적중 시 10~30점, 고양이 타격 시 20점 감점(최저 0점). 고양이는 메롱하며 놀리다가 내려갑니다.
- 두 캐릭터를 귀·눈 하이라이트·코·수염·볼·발 등이 묘사된 SVG 벡터 일러스트와 작은 표정 애니메이션으로 교체했습니다.
- 구멍 앞을 가리던 높은 잔디 배경을 제거하고 산뜻한 오락실 배경을 유지합니다.

### 소방서 게임
- 기존 60초 게임 / 불난 창문 클릭 / 3초 진화 / 단계별 다중 화재는 그대로 유지합니다.
- 몇 초 간격으로 아파트의 안전한 창문에 사람(🧒)이 등장해 구조 요청을 합니다.
- **🚒 소방차 버튼을 먼저 누르고 사람 있는 창문을 선택**하면 사다리차가 창문까지 뻗고 소방관(👨‍🚒)이 올라갔다가 사람을 데리고 내려옵니다.
- 구조 성공당 +250점과 구조 인원 수가 기록됩니다. 구조가 늦어지면 사람이 실내로 돌아가고 구조 기회를 놓치지만 위험·상해 연출은 없습니다.
- 화재는 기존처럼 불난 창문을 바로 터치해서 끕니다. 소방차 모드에서도 불난 창문 클릭은 진화 우선입니다.
- 결과와 이 기기의 순위 기록에 구조 인원을 함께 표시합니다. 예전 저장 기록도 유지합니다.


## 4. ⚽ 축구 승부차기 게임 — 슈팅 5단계, 고난도 키퍼 다이빙 (2026-10-31)

- 총 5번의 슈팅, 각 슛당 **10초**. 단계별로 실제 선택 가능한 구역이 **6개 → 5개 → 4개 → 3개 → 2개**로 줄어듭니다. 닫힌 구역은 회색 자물쇠 표시로 구분되고 터치할 수 없습니다.
- 각 단계에서 열려 있는 구역과 골키퍼가 막을 위치는 **플레이어가 선택하기 전에 모두 미리 무작위 확정**됩니다. 골키퍼는 슈팅을 보고 방향을 바꾸지 않습니다. 구역 선택은 공정하게 유지되며 해당 구역을 맞히면 선방, 다른 열려 있는 구역이면 골입니다.
- 무작위 슈팅 시 골키퍼가 막을 확률은 차례대로 **1/6, 1/5, 1/4, 1/3, 1/2**입니다. 따라서 후반일수록 골 성공이 어려워집니다. 마지막 단계에는 2개 구역 중 하나를 골라야 합니다.
- **골키퍼 애니메이션 업그레이드:** 공이 날아갈 때 골키퍼가 미리 정한 방향으로 팔을 뻗고 몸을 회전시키며 공중으로 다이빙합니다. 같은 구역이면 손에 공을 잡는 이펙트와 선방 효과가 나옵니다. 다른 구역이면 골망 반짝임, 그물 흔들림, 골 세리머니가 나타납니다.
- 기존 5번/10초 제한/기록 저장 방식은 유지. 단 게임 난이도가 바뀌어 **랭킹은 새 버전 별도 저장소(localStorage key v2)**로 분리했습니다. 이전 랭킹 데이터는 삭제하지 않지만 새 규칙 랭킹에는 합산하지 않습니다.
- 순위는 성공한 골 수 우선, 같으면 다섯 번의 선택 시간이 빠른 순입니다. **현재 휴대폰 또는 브라우저에만 저장**됩니다.

## 5. 🎈 김리안·권이준의 풍선놀이 (10단계 / 60초 도전)

- 풍선 **두 개의 색과 무늬가 같으면 짝을 맞히는 게임**입니다. 1~5단계는 색·무늬 맞추기, 6~10단계는 가려진 풍선의 위치를 기억하는 도전입니다.
- 단계별 풍선 수: **4, 6, 8, 10, 12, 16, 20, 24, 28, 32개**. 풍선 크기를 모바일 화면에 맞춰 **기존보다 조금 더 크게** 조정했으며 6열의 많은 풍선도 한 화면 폭 안에 표시합니다.
- 60초 전체 제한. 한 단계가 끝나면 **“완료! 다음 단계로 넘어가요!”** 문구와 자동 전환이 작동합니다.
- **10단계 모두 완료하면 황금왕관, 5회 불꽃놀이, 색종이 축하 효과, 승리 음악**이 나옵니다.
- 종료 시 **김리안 또는 권이준의 사진을 선택해 기록을 저장**합니다. 점수 우선, 동점 시 단계·맞힌 짝·남은 시간 순으로 이 기기의 상위 10개 기록을 보여줍니다. 중복 저장은 불가합니다.
- 랭킹은 현재 브라우저의 localStorage에만 저장하며 **서로 다른 기기와 동기화되지 않습니다**. 60초 안에 10단계 80쌍을 모두 맞히는 것은 매우 어렵기 때문에 도달 단계와 최고 점수 경쟁이 주된 목표입니다.
- 아동의 **얼굴 사진은 게임에 삽입**되어 공개 사이트와 공개 소스에서 방문자가 볼 수 있습니다. 원본 전체 사진은 업로드하지 않았습니다. 사진이 포함된 게임 파일의 공개·재공유에 주의해 주세요.
- 기존 색칠공부·두더지·소방서·축구 규칙은 유지합니다. 독립형 게임 파일은 `balloon-match.html`입니다.


### 기억력 힌트와 풍선 크기 개선

- **6~10단계**의 뒤집힌 풍선에서는 **'👀 전체 보기'**를 누르면 아직 맞히지 않은 풍선을 **3초 동안 모두 공개**한 뒤 다시 뒤집습니다. 다시 가리기 전에는 터치 선택이 잠겨 오입력되지 않습니다.
- 전체 게임 1회당 **최대 3회**이며 다른 단계로 넘어가도 남은 횟수만 이어집니다. 새 게임을 시작하면 3회로 재설정됩니다. 1~5단계는 풍선이 원래 공개되어 있으므로 힌트를 사용하지 않습니다.
- 특히 휴대폰의 **5열·6열 풍선을 약간 확대**하고 가로 스크롤이 생기지 않도록 크기 제한을 유지했습니다.
